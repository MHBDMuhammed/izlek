# Davranış Kuralları

Herkesin rahatça öğrenip katkıda bulunabildiği bir alan tutuyoruz.

- Saygılı dil kullanın; kişisel saldırı, taciz ve ayrımcılık kabul edilmez.
- Eğitim odağını koruyun; hız yarışı veya küçük düşürücü karşılaştırma yapmayın.
- Kişisel okuma verilerini istemeyin, paylaşmayın.

İhlal bildirimi için GitHub issue veya private vulnerability reporting
kanalını kullanın (güvenlik konuları için `SECURITY.md`). Bildirimler
repo sahipleri tarafından değerlendirilir; yanıt süresi vaat edilmez.
